VOYANA v1.1 – INSTALACJA

1. Utwórz publiczne repozytorium GitHub: voyana
2. Rozpakuj ZIP.
3. Wgraj wszystkie pliki ze środka folderu Voyana_v1_1 do głównego katalogu repozytorium.
4. Settings → Pages → Deploy from a branch → main → /(root) → Save.
5. Otwórz: https://TWOJA-NAZWA.github.io/voyana/
6. Na iPhonie otwórz w Safari: Udostępnij → Dodaj do ekranu początkowego.

Ceny w tej wersji są demonstracyjne. Aktualne dane wymagają API.
